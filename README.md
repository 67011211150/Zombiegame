# Project Zomboid: Web3 Survival

เกมยิงซอมบี้ 2D มุมมองจากด้านบน (Top-down Shooter) ที่เชื่อมต่อกระเป๋า MetaMask บนเครือข่าย BNB Smart Chain Testnet

จัดทำโดย นายศิริวัฒน์ ไพรพฤกษ์ รหัสนิสิต 67011212141
มหาวิทยาลัยมหาสารคาม

## วิธีเล่น

| ปุ่ม | การทำงาน |
|---|---|
| W A S D | เดิน |
| คลิกซ้าย (กดค้าง) | ยิงปืน |
| R | รีโหลดกระสุน |
| B | เปิด / ปิดร้านค้า |

- ฆ่าซอมบี้ให้ครบตามเป้าหมายเพื่อขึ้น Wave ถัดไป ซอมบี้จะแข็งแกร่งขึ้นทุก Wave
- เก็บชิ้นส่วนซอมบี้และไวรัสบอสที่ดรอป แล้วนำไปขายแลก BNB ในเกมที่ Safe Zone
- ใช้ BNB ในเกมอัปเกรดปืนและซื้อเกราะ ราคาจะเพิ่มขึ้น 1.5 เท่าทุกครั้งที่ซื้อ
- Safe Zone ซอมบี้เข้าไม่ได้ และจะฟื้นเลือดกับเกราะให้ แต่ยิงปืนไม่ได้

## ประเภทซอมบี้

- ซอมบี้ธรรมดา: เดินช้า
- ซอมบี้วิ่ง: ตัวเล็ก ตาแดง วิ่งเร็ว (เริ่ม Wave 2)
- บอสยักษ์: เลือดเยอะ ตีแรง ดรอปไวรัสบอส
- บอสเวทมนตร์: ยิงคาถาใส่ผู้เล่นได้ (เริ่ม Wave 3)

## ระบบ Web3

- เชื่อมต่อกระเป๋า MetaMask
- สลับไปเครือข่าย BSC Testnet ให้อัตโนมัติ (ถ้ายังไม่มีจะเพิ่มให้)
- แสดงยอด tBNB จริงในกระเป๋า
- ทุกการซื้อขายในร้านค้าต้องเซ็นยืนยันผ่าน MetaMask (ฟรี ไม่เสียค่าแก๊ส)
- รองรับการเปลี่ยนบัญชีและเปลี่ยนเครือข่ายระหว่างเล่น

หมายเหตุ: BNB ที่ได้จากการขายไอเทมเป็นสกุลเงินในเกม ไม่ได้โอนเข้ากระเป๋าจริง

## วิธีเปิดเกม

MetaMask จะไม่ทำงานถ้าเปิดไฟล์ด้วยการดับเบิลคลิก ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เลือกวิธีใดวิธีหนึ่ง

**XAMPP**
1. คัดลอกไฟล์ `index.html` ไปไว้ที่ `C:\xampp\htdocs\zombie\`
2. เปิด Apache ใน XAMPP Control Panel
3. เข้า `http://localhost/zombie/index.html` ด้วย Chrome ที่ติดตั้ง MetaMask

**VS Code**
1. ติดตั้งส่วนขยาย Live Server
2. คลิกขวาที่ `index.html` แล้วเลือก Open with Live Server

**GitHub Pages**
เปิด Settings > Pages ของ repo นี้ เลือก Branch `main` แล้วเข้าเล่นผ่านลิงก์ที่ GitHub ให้มา

## เทคโนโลยีที่ใช้

- HTML5 Canvas และ JavaScript
- ethers.js 5.7.2 และ MetaMask (EIP-1193)
- Web Audio API (สร้างเสียงในโค้ด ไม่ใช้ไฟล์เสียง)
